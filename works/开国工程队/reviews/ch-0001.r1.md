# 第 1 章 审稿（第 1 轮）

- 正文版本：1

- [x] Q1 :: 开头「老齐，退车」及随后的对讲机对话 :: 设定里齐大山是挖掘机手，正文开头却让他开着装载机在槽底退车，后面又坐进挖掘机驾驶室，同一章内开了两台车。 :: 开头的退车命令给装载机司机（不给名字），老齐的挖掘机一开场就停在槽东头。
- [x] Q2 :: 「四十六个人的名册念完……报数：人四十六」 :: 沈彻刚下的第三条命令是「人、车、油、水、粮、药，一样一样过」，正文只报了人；油、水、粮这些决定能撑几天的数字一个都没出，本章的处境其实没交代清楚。 :: 补一段林小满念油、水、粮的账，把「两天」这个时钟摆到台面上。
- [x] Q3 :: 全章清点段落 :: 设定里拌合站有三个人留守，落地后对讲机喊不通、再没出现；正文清点报成 46 人一个不少，把这个缺口抹掉了，卷二技术外泄的线头也断了。 :: 清点时报出「现场 46，拌合站 3 人未归」，留一句沈彻的处理。
- [x] Q4 :: 结尾何秀台词「我最多等到天亮」 :: 挤压伤 17:06 救出，到 23:41 已过六个半小时，何秀说还能等到天亮（约七小时后）在医学上不成立，也消解了她自己的紧迫感。 :: 把期限改成后半夜两点，并让沈彻的手表时间和这个期限咬合。
- [x] Q5 :: 「他爬到挖机履带上，站起来，转了一圈」 :: 渠槽八米深，站在履带上只能看到槽壁和土堆，看不到四面荒原，「西边没有高压线塔」的观察在物理上站不住。 :: 让他爬上翻土堆成的土坡顶再环视。
- [x] Q6 :: 老齐：「有人干过活，就有水。荒地里没人修墙。」 :: 这句太书面，跟老齐「开三千里、骂人、护机子」的口吻不合，像作者替人物说话。 :: 换成更糙、更具体的西北机手话。
