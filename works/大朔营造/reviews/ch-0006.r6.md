# 第 6 章 审稿（第 6 轮）

- 正文版本：5

- [x] Q1 :: 未标注 :: 四十八那节“十六傍晚，墙根拆完了……八步根”之后，十七日又写给夯土从“这八步的墙根底下”一层层挖土，与已宣布拆完的墙根冲突；且原说八步要五天半，实际因凿、筛而只用三天多，赶工压力被无声消掉。 :: 未给出建议
- [x] Q2 :: 未标注 :: “一块二”到底是最后的干粮量还是天数说不清：既称“最后的”又次日“把那一块二切了”，半块分给众人，“明天早上分完”之后还继续有余粮可偷，口径前后不一致。 :: 未给出建议
- [x] Q3 :: 未标注 :: 偷吃的时间对不上：阿六自己说是“昨天夜里刨墙根，刨到二更”，但十六日白天已拆完墙根，十六夜并不刨墙；苗青又断言“十四还在，十五还在”，与上述叙述互相矛盾。 :: 未给出建议
- [x] Q4 :: 未标注 :: 夯具与人力口径几处对不上：江崇说“二尺二，够做夯头……两个人抬”，实际是抬夯四人一拨、喊号子，尺寸也偏短；韩松算需要“八个”，周砚答“五个半”，现场却有阿六、石头、两个女人、郑老栓、周砚、韩松七人，且祝敏图账在列，人数始终没定准。 :: 未给出建议
- [x] Q5 :: 未标注 :: 人数口径混乱：灶边是“十五个人”，郑老栓却自称“俺们这十一个”，后文统计又成十六口，三者没交代差在哪（孩子、孕妇、韩松等是否计入）。 :: 未给出建议
- [x] Q6 :: 未标注 :: 验收结论与当晚发现相矛盾：十九晌午韩松判“土干透了，夯透了……过了”，夜里周砚一摸就摸出三处起皮发软，前文的“硬了”缺少依据或缺少交代（表层松土与内部酥松的界线没立住）。 :: 未给出建议
- [x] Q7 :: 未标注 :: 对话套话与重复句式密集：“这话算不算数／算数”“按账办”“写下来”“这不是我要的做法”“凿一遍等于没凿”等在数节内反复出现，郑老栓的追问两轮几乎同构，削弱了冲突推进。 :: 未给出建议
- [x] Q8 :: 未标注 :: “八步”这个核心数目没交代清楚：既指墙长八步，又指拆、凿、筛、夯各道工序的计量单位，读者无法判断每一步多长，进度（“拆了一步半”“两天，八步根”“三步”）因此失去可比性。 :: 未给出建议
