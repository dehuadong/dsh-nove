# 第 6 章 审稿（第 5 轮）

- 正文版本：5

- [ ] Q1 :: 未标注 :: 人数口径前后不统一：祝敏可点名的只有八个加两个诨号、两个小名和一个孕妇，共十三人，但周砚却说“十六口，报十六个名字”；同一章里又有“十五个人围着灶”和郑老栓自称的“俺们这十一个”。 :: 未给出建议
- [ ] Q2 :: 未标注 :: 人手数算不通：韩松按工序算出“八个，我们没有八个”，周砚回答“五个半”，但紧接着的排班是抬夯四人、筛土两人、凿毛两人，另有郑老栓铺土、周砚与韩松砸背；而且营里既然有十五口人吃得下饭，正文又没交代其余人为什么不能上工。 :: 未给出建议
- [ ] Q3 :: 未标注 :: 拆墙工期对不上：十三后晌半天只拆了一步半，韩松据此估“八步要五天半”，可十六傍晚却写成“四个人，两天，八步根”；实际是从十三到十六干了三整天，而且“四个人”里只提到阿六、霍七、周砚三个。 :: 未给出建议
- [ ] Q4 :: 未标注 :: 验收第二条的理由被同章结尾推翻：韩松说没有雨雪就验不了，并断言“雨一落，墙头会起皮”，可当夜没有雨雪，周砚已经摸到起皮和三处软土；起皮的征兆在没有下雨时就出现了，韩松“验不了”的坚持因此失去依据，墙却仍被记为“第一条过”。 :: 未给出建议
- [ ] Q5 :: 未标注 :: 同一堵墙得出相反结论：十九晌午周砚跺墙后判断“土干透了，夯透了”，入夜在墙头却“指头一捏，土碎了，底下的土是软的”，正文没区分表层松土和收顶压得浅，读者会觉得这两处判断互相打架。 :: 未给出建议
- [ ] Q6 :: 未标注 :: 干粮的处置前后不一：十三夜苗青说“明天早上分完”，次日却把半块“不出筐”留起来；十四日说这半块是给孩子和孕妇的，十六日又改成“这是给肚子里那个的”，口径和分量都没有对上。 :: 未给出建议
- [ ] Q7 :: 未标注 :: “一边拆一边夯”的方案没有兑现，也没有交代原因：周砚说把夯提到前头，好趁土没冻住赶紧夯，但后文却按拆完根、再凿毛、最后夯的顺序推进。读者看不出这个决定是被推翻了，还是被忘了。 :: 未给出建议
- [ ] Q8 :: 未标注 :: 问答和动作重复成了固定模板：郑老栓反复问“这话算不算数”，周砚、祝敏反复答“算”，韩松的“炭条”动作也三度出现（夹在指头缝、在指甲上磕断口、在图纸上划）；这几处功能相同的对白和动作没有变化，读起来像同一段情节。 :: 未给出建议
