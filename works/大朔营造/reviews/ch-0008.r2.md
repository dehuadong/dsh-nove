# 第 8 章 审稿（第 2 轮）

- 正文版本：2

- [x] Q1 :: “图上写：官堡，界外，堡内无井，水由营内供给。” :: 【高·patch】Q3 仍存：第 7 章秦老卒亲口说“我这堡里头也有一口”，周砚答应注“堡内私家井一口”，图注落成“堡内井一口”；本章书吏却从同一根竹管里念出“堡内无井”，周砚还答“我写的”。同一张图两句相反，点验可信度与周砚信用一起倒。 :: 按已定口径 A（保留私家井、第 7 章不动）改本章三处：周砚答“堡里有一口，早年干了，不供营里”；书吏追问改“井干了，为什么住人”；图注念“官堡，界外，堡内井一口，水由营内供给”。
- [x] Q2 :: “堡外三户，八口。你是一口。” :: 【高·patch】Q2 只改了一半：第 5 章是三户逃户八口，秦老卒是看堡老卒、另算一口；本章把他算进八口，“一口井，供二十四口”就少算一人（应二十五口），堡水两担也少他一份。全章是点数，官差数错，“一根不少”就不作数。 :: “你是一口”改“你另记一口”；书吏另落一行“堡兵一口，无名，按口算”；“供二十四口”改“二十五口”；堡水仍记三户八口、日两担，另注“堡兵一口，水自挑”。
- [ ] Q3 :: “从井台到这里，二十八丈。” :: 【中·patch】与第 7 章步值打架：同一根北桩第 7 章写“五十六步……一步一尺四。合七十八尺四寸”（七丈八尺四），本章作二十八丈，差二十丈；四至“北至井北五十六步”只有按一步五尺才等于二十八丈。本章口径对，错在第 7 章那句。 :: 需重开第 7 章，把“一步一尺四。合七十八尺四寸”改为“一步五尺。五十六步，合二十八丈”；本章不动。
- [x] Q4 :: “六天。八个人。” :: 【中·patch】第 4 章初八苗青说“现在四尺二，从见水到现在，挖了不到一尺”；本章说整口井六天挖成、出土一百五十五方尺（正合三尺口径×二丈二深），四尺二到二丈二的十七尺从未交代何时加深，土方数就是凭空来的。 :: 改“头一段六天，八个人。十三日淘井，又往下掏”，出土句改“前后一百五十五方尺”；借本章已有的“十三日淘井”把加深安进去，不动第 4 章。
- [ ] Q5 :: “九根桩，一根不少。步是五尺，一尺不差。” :: 【中·patch】桩号本身对（东三南二西二北二＝九根，与第 7 章桩号一致），但第 7 章收尾写“二十七根桩，四至写全”，桩号只列出十根（含井台零桩）。二十七与九对不上，官差漏数十八根还夸“一根不少”。 :: 第 7 章“二十七根桩”改“九根界桩”（草杆另写“九根桩、二十七根草杆”）；本章九根不动。
