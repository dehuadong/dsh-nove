# 第 6 章 审稿（第 3 轮）

- 正文版本：3

- [x] Q1 :: 第一节，“八步要五天半。剩下两天半，夯不完一丈八” :: 数不对：从十三到十九一共七天，拆要五天半，剩一天半，不是两天半。润色时顺手把这个数改对。 :: 改成“剩下一天半，夯不完一丈八”，周砚接话的逻辑不变。
- [x] Q2 :: 第二节两处：“灶边没有人说话。阿六把碗舔了一遍”（十三夜）与“灶边没人说话。”（阿六认错之后） :: 两处用的是同一个句式，隔得又不远，读起来像同一块砖用了两次。 :: 后一处换成具体动作收场（放下碗、没人抬头），并把江崇的动静接进去。
- [x] Q3 :: 第三节，“凿一遍等于没凿”到韩松写图纸一段 :: 两人争的是工序，台面上却是连着几句短对白，缺少手上的动作；“两头的规矩按你说的做”一句语气也偏松。 :: 润色时给韩松加一个手里的动作（炭条、撬棍），并把周砚那句改成把责任说死。
