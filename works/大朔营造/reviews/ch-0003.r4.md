# 第 3 章 审稿（第 4 轮）

- 正文版本：5

- [x] Q1 :: 第二节后半【井盖盖到第三遍才成】到第三节开头【初六，搬家搬到天黑】 :: 场景时间锚点重复：第二节从初五写到“第三遍在初六晌午”，接着又写了粮坑开挖，第三节却重新从“初六，搬家搬到天黑”开头。读者无法判断埋粮在搬家之前还是之后，而这两件事都在初六、且都需要人，“今天搬”与“挖坑埋粮”谁先做正是本章的士气问题。 :: 把井盖与粮坑明确切到初五，初六只留搬家与做旧；或在第三节开头改“初六，天没亮就搬”，再让埋粮句回到初五那一段。
- [x] Q2 :: 第二节【第三件，人和火都缩。今天就搬，搬到柳丛后头那道坎下】 :: 指令与实际不符：周砚当场下的令是“今天就搬”，正文里真正搬家发生在初六（第三节），中间隔了一夜；而“白天不点火”的隐蔽要求当晚就生效，时间上对不上。 :: 改成“明早天亮前搬”，或把第三节开头改成“初五当天搬，搬到天黑”，二者选一。
- [x] Q3 :: 第一节【郑老栓把手伸进那条两指宽的缝里】 :: 物件先于制造出现：初五清早郑老栓就摸到了“两指宽的缝”，而井盖要到初五晌午才第一遍盖上、才有那条缝；全章后文反复用这条缝（改斜、横进半尺），来历却没交交代清楚。 :: 在第一遍盖井处补半句：井口原有一条旧缝（第二章挖井留下的缺口），这次要把它改成能引罐的缝；或第一节改“槽”与“盖上的缝”分开说。
- [x] Q4 :: 第二节【霍七说了三个字，停了停，又补一个】 :: 计数错：前面报了“粮。锅。盐。女人。”四样，再补“铁”共五样，却写“说了三个字”。这种数目字在本章是可信度基础，错一次读者会连后面的战方、口粮账一起怀疑。 :: 改成“霍七说了四样，停了停，又补一个”，或删去“女人”改成三样。
- [x] Q5 :: 第四节【“你说四百人没马。”周砚说。】 :: 归错话：于三在本场只说了“四百人，走三天，不进城，不进营子”，从来没说没马；周砚手里这句情报是霍七在第二章给的。当面把别人说的话扣到对方头上，会让于三后面的辩解（“营里没马”）失去前提。 :: 改“霍七说你们四百人没马，你倒说有马”，或改“队里没马？”让于三自己把话掉出来。
- [x] Q6 :: 第二节【三天以后，欠的补回来——每人每天补到八分之一，我记着】 :: 数字方向矛盾：干活的人原本按五分之一块，砍后是十五分之一，而“补回来”补到八分之一——对干活的人是降，对全营日耗是从两块四降到两块，总量反而管得更紧，这在人物口吻（周砚给数字必自洽）和读者算账上都说不通。 :: 把“补”改成具体的两档：三天后干活恢复五分之一、不干活恢复十分之一；若要体现惩罚延续，写成“多干的先补到八分之一，不下地的还是十五分之一”。
- [x] Q7 :: 第三节【她按住郑三的手腕数了一阵…“五天。”她冲江崇那边说】 :: 判决无依据：苗青整夜只处理了郑三，没看过江崇的腿（初四判的三天已到期），却直接把禁令改成五天；原稿里“初七早上解开布带看一眼”的动作在修订中丢了，专业判断变成随口加码。 :: 在她开口前补一行动作：跪过去解开江崇的布带，摸摸脚踝外侧，布带重新缠紧，再开口“五天”。
- [x] Q8 :: 第二节【俺在黑石口的营里就闻过这味儿】 :: 世界口径报错：郑老栓在第三节说的是“到黑石口死了三个…过了黑石口那一夜又走散了五个”，黑石口是路边死人的地方，没有一个“营”；石头这句话凭空多出一个“黑石口的营”，与同一章的人物叙述冲突。 :: 改成“俺们在黑石口捡的那半袋就这味儿”（豆子来历交交交代），或让郑老栓接一句“兵过以后留下的营盘里拾的”。
- [x] Q9 :: 文风基准要求：单位错位保留（内部说米、立方，对屯户改口说步、丈） :: 本章一次错位都没有：周砚对韩松直接说“三十六方土”，对郑老栓改口说“碗、天”，但“立方/米”这一层只有否定，没出现正面错位，等于文风基准里指定的那一项细节全章缺席。 :: 在韩松算战方处加一拍：周砚脱口说“三十六立方”，韩松接“方就方，别跟屯户说立方”，后面给郑老栓说话时自动换成“方、步”。
- [ ] Q10 :: 章纲 outline/ch-0003.plan.md 与本章正文 :: 两套数值共存：章纲写“补一丈高的堡墙要三百方土、十六个人半个月”“账上是十六块往下走到十一块”，正文是三十六方土、三天二十四方、十六块半到九块三。正文内部已自洽，章纲没跟上，后文查设定会踩到两个版本。 :: 以正文为准回改章纲的阻力与代价两项（三百方/半个月→三十六方/三天二十四方；十六块→十一块→十六块半→九块三），必要时同步更新真值里的 plan。
