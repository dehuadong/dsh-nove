# 第 7 章 审稿（第 3 轮）

- 正文版本：6

- [x] Q1 :: “五十六步。”周砚说，“一步一尺四。合七十八尺四寸。” :: 【高·patch】一步一尺四与本回其他处“五尺铁尺”、“北至井北五十六步”的四至自相矛盾：按一尺四算五十六步只有七丈八尺四，按五尺算才是二十八丈；第 8 章书吏按二十八丈讯桩，两章对读差二十丈。 :: 改为“一步五尺。合二十八丈。”，与五尺铁尺、四至、第 8 章一致。
- [x] Q2 :: 郑三把最后一根桩砸完，天擦黑。二十七根桩，四至写全。 :: 【中·patch】同段列出的桩号是东一东二东三、南一南二、西一西二、北一北二、井台零桩，只九根界桩；“二十七根桩”与桩号数量对不上，第 8 章书吏按九根点验、说“一根不少”就落了空。 :: 改“九根界桩，四至写全”，草杆与桩分开说。
