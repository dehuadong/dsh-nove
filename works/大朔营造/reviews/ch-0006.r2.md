# 第 6 章 审稿（第 2 轮）

- 正文版本：2

- [x] Q1 :: 第三节，“筛两个，抬夯一拨，凿毛两个。”……“三拨。我们没有三拨” :: 人数单位混着数：筛和凿毛报的是人头，抬夯报的是“一拨”，接着又说“三拨”，读者算不出到底要几个人，也接不上一句“五个半”。 :: 统一成人头：筛土两个、抬夯四个、凿毛两个，共八个；后文“我们没有八个”接五个半。
- [x] Q2 :: 第四节结尾，“明天，水再泼一遍，看还起不起皮” :: 与同一场里韩松的话直接打架：韩松刚说过“拿水泼？泼一桶水，看不出来”，结尾又让周砚拿泼水当验法。 :: 改成周砚对起皮的处置：明天把这八步的墙头铲半尺、重夯一遍，用活回答韩松那条不签的验收。
