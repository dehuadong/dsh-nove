# 第 3 章 审稿（第 2 轮）

- 正文版本：3

- [x] Q1 :: 祝敏算粮那一段：“每人每天八分之一块，挖土和盖井的加一份，一共动五块半” :: 按这口径算不平：十六人×八分之一×3 天=六块，还没算“干活的多一份”；却报“动五块半、剩十一块”。账上差一环，而这一章的主题就是账。 :: 把口径改成能验算的：不干活八分之一，干活四分之一；三天七块五——存粮不够，先扣到每人十分之一，七块五变四块八，再四舍五入报“五块半”。或者直接改成“动六块，剩十块”。
- [x] Q2 :: 霍七“四百来人，没粮，没马”与于三“他有一匹马” :: 两句直接打脸，而且就在同一章；读者会认为作者忘了自己写过的数。 :: 让矛盾有人处理：周砚或霍七当场把这个漏顶回去，于三回“队正的马算他的，不算营里的”——一句话把溃营的规矩立起来。
- [x] Q3 :: 井盖第三遍、搬家、于三到场三个节点 :: 只有开头“十月初五”和结尾“初七”，中间两段没日期；读者会把三天的事当成一天里做完的。 :: 在“井盖盖到第三遍”和“搬家搬到天黑”两处各挂一个日期（初五/初六），并让火堆、粮坑的进度跟着变。
- [x] Q4 :: 郑老栓提“城里有个远亲” :: 他一辈子怕“官家许了话、随后把人拉走”，往城里投亲正是最容易被拉走的去处，却没一句自反；把他写得太顺了。 :: 让他自己把这层说破：城里也不是没人拉人，他只是没别的地方去——这样“留下”才是个决定，而不是认命。
