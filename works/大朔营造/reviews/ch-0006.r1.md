# 第 6 章 审稿（第 1 轮）

- 正文版本：1

- [x] Q1 :: 第一节末，“天黑以后，十五个人围着灶。锅里是白水煮的菜根，没盐，只有一点去年剩下的酱渣” :: 与粮账对不上：第十章（第 5 章）记的是干粮六块八、一天一块二、到十月十四。十三这天还有干粮，却在十三夜里就只喝菜根汤，读者会以为账是假的。 :: 十三夜里照旧分干粮，让苗青把最后一块二亮出来说“十四早上分完，十五起喝汤”；菜根汤往后挪到十四夜。
- [x] Q2 :: 第二节，“十五，天没亮……早饭是苇根汤” :: 苇根没有来路：前文没交代沟底有芦苇荡、也没写谁在哪天挖的，断粮第一顿凭空就有了。 :: 在十四下午或十五清早补一两句：霍七下沟踩点，看见苇子荡，挖回一斗根；苗青说“苇根发涩，得泡一夜”。
- [x] Q3 :: 第三节，“昨天夜里抬夯，抬到二更，手抖，站不住” :: 时间线矛盾：抬夯是十七才开始的事，阿六偷粮在十六夜，前天夜里还没有夯可抬。动机因此立不住。 :: 把“抬夯”改成“筛土”或“刨墙根”，并写清是哪一段活让他手抖；或者把偷粮改到十八夜、另给一条动机。
- [x] Q4 :: 第二节到第三节，十五、十六两天 :: 工程线断了：这两天只写了打猎挖根，没写八步墙根拆到哪一步、谁在干活。读者不知道十八个工是怎么赶回来的，十九验收就来得太容易。 :: 在十六傍晚补一段进度：剩下的四个人接着拆根、烧墙根，天黑拆完八步，韩松报“根拆完，明天上凿毛”。
- [x] Q5 :: 第三节开头，“十七，土要用了”；全章未出现凿毛 :: 工艺与前文打架：韩松在第五章反复说过，新土必须落在老墙面凿毛的头上，否则“两层光面摞在一起，一推就滑”。本章直接夯土，把这道关键工序漏了。 :: 加一小场凿毛：拿旧撬棍和石头把老墙面凿出麻面，半天只出得到三步；因为赶不及，周砚把凿毛范围定在八步的两头各两步，其余靠加宽墙脚压住——并写明这是他自己拍的板。
- [x] Q6 :: 第四节，“抬夯的是阿六和石头，四个人一组，喊一声压一声” :: 人数含糊：前面韩松刚说“五个半劳力”，这里写成两个人名又是四个人一组，读者算不清到底几个人在抬夯。 :: 写实：一夯四人（阿六、石头加两个女人），郑老栓在底下铺土，周砚和韩松轮着砸背检查。
- [x] Q7 :: 第三节，苗青与祝敏处置偷粮的一段 :: 主角缺席：连断粮带偷粮这一章最硬的一场，周砚只在末尾问了一句“谁动的”，他该有的处置不在了。 :: 让周砚当场把自己的那一份拨给孕妇，并说清“不罚饿，只记账”；与被偷的那一份形成对照，也照住他“不拿人命换速度”的底线。
- [x] Q8 :: 全章 :: 韩松的“最土的比喻”只出现一次，“你知道为什么这法子省吗”后面接的是账，不是土话；人物声音比前几章薄。 :: 在筛土或夯层起皮那段补一句土比喻（例如“土跟面一样，没揉透，蒸出来是夹生的”），让他的解释先落到手上。
