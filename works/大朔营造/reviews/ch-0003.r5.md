# 第 3 章 审稿（第 5 轮）

- 正文版本：6

- [x] Q1 :: 第二节【“那就砍。”周砚说…“不干活的回到十分之一”】到【“补。”周砚说】 :: 裁剪账的逻辑链断开：周砚先说“砍”，但同一句里又让不干活的“回到十分之一”——那是原额，等于不砍；接着苗青反对“砍到十五分之一”，可十五分之一是谁都没定过的数；祝敏又根据这个不存在的数算出两块一。读者一算就懂，四人对话全在空转。 :: 改成一条真链条：周砚定“不干活的砍到十五分之一”→苗青“人走不动路”→祝敏“砍下来两块一能到十月十五，不砍两块四只到十月十四”→周砚听完数改口“不砍了，少一天，换八个人能站着走路”。
- [x] Q2 :: 第一节韩松算墙（接上轮 Q10） :: 三百方、半个月这组数在正文里还没有落点：正文只有“东墙塌得最狠的一段、三十六方”，而章纲写的是“一丈高堡墙要三百方土、十六个人半个月”，两套数各说各的，看图查设定的人会踩到两个版本。 :: 在韩松报数时把两笔分开：整道墙三百方、半个月；只补东墙塌下去这一截三十步、三十六方——一个是整面，一个是这一截，同一套账。
- [x] Q3 :: 第三节开头【初六，天没亮就搬】到【天刚亮，周砚扒开井盖看了一眼】 :: 搬家当口跳场：上一句还在搬，下一句他已经在洼地扒井盖，中间没有交代他为什么离队、车上那阵怎么扔下的，读者要在两句之间自己补一个来回。 :: 给个因由和接续：搬第二趟的时候他才拐回洼地，看一眼又回去接下一趟，或让韩松搭一句“你先去，车我盯着”。
- [x] Q4 :: 第三节【晌午，周砚一个人回洼地，把那条豁口改斜】 :: “三遍才成”的结构断了：前文有“第一遍在初五晌午”“第二遍在初五夜里”，到真正的第三道手变成一句“把豁口改斜”，没编号、没交代为什么前两遍不算成，前文的编号白编。 :: 补上“第三遍在初六晌午”，并说明前两遍为什么不收：前两遍只是在堵土，第三遍是换方向——只有换方向才藏得住水面。
- [x] Q5 :: 第二节【火边没人说话】与第三节【三样东西摆在那儿，谁都没说话】 :: 同一个反应句在一章里出现两次，第二次的情绪力度被第一次吃掉，读者会觉得作者只有一个句式。 :: 留一处“火边没人说话”，第三节改成动作反应：老头把布袋口重新系上，或石头把手缩回去。
- [x] Q6 :: 第二节粮坑段【粮坑挖在柳丛根下】 :: 时间锚缺失：井盖第一遍标了初五晌午、第二遍标了初五夜里，粮坑只写“挖在柳丛根下”，读者不知道这是初五下晌还是初六；而初六他们要搬家，埋在旧营地的坑和搬家的顺序直接影响“米粮到底带走了没”。 :: 粮坑段开头补一句“初五下晌”，并点明三个坑留在旧洼地、搬走的是人，不是粮。
- [x] Q7 :: 第二节石头问半袋豆子【那半袋豆子呢？】 :: 豆子来历空白：石头问“为什么不吃”，正文只说“留到最后”，没交代这半袋豆子是谁的、从哪儿背来的，读者无法判断它到底是口粮还是兵器，前面那份紧张就悬空。 :: 让石头自己把来历说出来：“就剩这半袋，俺们从沟外背进来的，八十里”，然后周砚再压“留到最后”。
