# 第 8 章 审稿（第 1 轮）

- 正文版本：1

- [x] Q1 :: “井深一丈二尺。见水四尺二。” :: 【高·patch】井深三处并存：本章写一丈二尺，第 7 章定稿写“井深二丈二尺”（韩松提水处），第 2、4 章只有“四尺二见水”“从见水到现在挖了不到一尺”。同一口井差一丈，点验的核数就成了随便写的；“出土八十方尺”是照一丈二算的，井深一改这个数也得跟着改。 :: 先定一个井深。按第 7 章定稿（二丈二尺）：本章两处改二丈二尺，出土改约一百五十五立方尺。按一丈二尺：第 7 章那处要改回一丈二，且第 7 章得重开。另在第 4 章之后补一句何时加深，否则“四尺二见水”与两丈深对不上。
- [x] Q2 :: “堡外三户，七口。” :: 【高·patch】第 5 章写明狼牙堡三户逃户是“两个男人、四个女人、两个娃”，共八口，秦老卒另算；本章记成七口，后面“一口井供二十三口”“堡水日两担”全跟着少算。老读者一对照就知道人数被改过。 :: 三处“七口”改“八口”，秦老卒另记一口；“二十三口”改“二十四口”（连秦老卒则二十五口），堡水日两担按新人数复核。
- [ ] Q3 :: “图上写：官堡，界外，堡内无井，水由营内供给。” :: 【高·patch】第 7 章正文里秦老卒亲口说“我这堡里头也有一口”，图注写“官堡，界外，堡内井一口”；但真值日志（第 7 章 seq147）记的是“其堡内无井”。读者读到的是“有一口”，本章书吏却从同一根竹管里念出“无井”，点验的可信度当场就没了。 :: 先定口径：按真值与本章章纲（全滩只有一口井），须回改第 7 章秦老卒那句与图注，去掉私家井；若保留私家井，本章改“堡内私家井一口，不供营里”，周砚“堡里没井”也得改口。无论哪条，第 7 章都要重开一并改。
- [x] Q4 :: “干粮还有一块二。” :: 【高·patch】第 6 章苗青当众报过“一块二。十四日分完，十五起没有干粮”，十六日阿六又把筐里留给孕妇的半块吃光；到二十二日不可能还有一块二。这句还正好和祝敏“现粮四斗二升”的紧账打架。 :: 改“干粮没了，苇根还剩两把”，或让苗青报当日实数并与四斗二升对得上；不要再用“一块二”。
- [x] Q5 :: “东三，南二，西二，北一。九根。” :: 【高·patch】三加二加二加一只有八根，随后也只走了东三、南二、西二、北一这八根；第 7 章桩号是东一东二东三、南一南二、西一西二、北一北二，共九根。数对不上，“九根桩，一根不少”这句落点就落空了。 :: 改为“东三，南二，西二，北二”，走桩段补走北二一根；或把总数改八根并同步第 7 章桩号。
- [x] Q6 :: “一步。五尺。” :: 【中·patch】书吏逐对桩用五尺铁尺量“一步五尺”，但第 7 章四至是东二十二丈、南二十八丈、北五十六步（合二十八丈），桩分布在二十二到二十八丈之间，相邻两根不可能都是五尺；北一“二十八丈”又称是五尺尺子量出来的。读者一算就知道这段是摆样子。 :: 二选一：①书吏只抽量一段步距（连量五步合二十五尺）核对“步”这个单位，总长按绳与四至对；②按四至逐至核总长（东二十二丈、南二十八丈、西让一尺、北五十六步），删掉逐对“五尺”。
- [x] Q7 :: “一根弦三尺，十九根五十七尺。一斤麻出四尺。” :: 【中·patch】五十七尺除四，是十四斤四两；下文周砚说“十五斤”、江崇说“十五斤，一两不少”，多出十二两，和“一两不少”的精确口气正好相反，硬核账就松了一格。 :: 改“十四斤四两”；若要整斤备料，另写“按十五斤备，余数记损耗”，别再说“一两不少”。
- [x] Q8 :: “我们没跑。” :: 【中·patch】第 7 章霍七自己说过“我带七个人跑出来，到了沟口剩三个。兵册上我是没开仗就跑”；本章这句“没跑”与他自述相反，周砚又没有辨析，读者会以为要么霍七在撒谎，要么前文写错。 :: 改“我们没开仗就散了”，周砚接一句“溃散，不是逃”，把“溃”与“逃”的界线当场说清——正好回击书吏“查不清是逃”。
