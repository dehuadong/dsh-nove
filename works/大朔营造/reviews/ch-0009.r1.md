# 第 9 章 审稿（第 1 轮）

- 正文版本：2

- [x] Q1 :: “从垛口到北一桩，五十六步。一步五尺，二十八丈。”／“补到一丈八的，几步。” “三步半。” :: 【high】墙长台账另起一套，与前文桩距、土方、已完工段三处对不上：北一桩在井台正北二十八丈（第 7、8 章），本章把同样五十六步给成「垛口到北一桩」，等于把垛口摆在井台上；已到一丈八只算三步半，而第 8 章明写八步垛口十九日收顶、高一丈八；待补五十二步半按一步一方二约六十余方，超过第 5 章整段塌口三十七步、五十四方的总量。读者一路跟着韩松数墙，一算就发现垛口和井台重合、待补的墙比整段塌口还长，后面「十五方，十二步半」的换算随之悬空。 :: 先定一条能站住的距离：北一桩在井台正北二十八丈，垛口在塌口那一截，二者不是同一条线，把「垛口到北一桩」改成一个与之相容的实数（例如从垛口往北到北一桩四十七步），再按新值重算待补步数与方数；已到一丈八的一段写成「八步」（八步垛口十九日收顶），别写成三步半；待补长度不得超过第 5 章的全塌口三十七步、五十四方。
- [x] Q2 :: “三样齐了才算一行。名字补不出，按丁算。”／“三行齐了。石头后面韩松，阿六后面郑老栓，二小后面刘四。郭氏按丁。” :: 【high】「保」被当成「名」的替补，跟祝敏自己刚定下的规矩和书吏的原话打架：规矩是「名字、籍、保三样齐了才算一行，名字补不出按丁算」，书吏说过「诨号不入册」，但三行始终没有本名，只写诨号或小名加保人，祝敏就宣布「三行齐了」，反倒只知夫家姓的郭氏按丁。读者记得书吏那句「诨号不入册，三日内补」，会算不出这三行凭什么算填齐；章末「十六行，全有字了」这个唯一战果站不住。 :: 让祝敏在落笔前把规矩改一次口，把保写成顶名字的办法：「名字补不出，有在册人作保，算一行；保人垫口粮」；再让她补一句「书吏回来认不认，三天后才知道」，把风险留在纸上。若不想改规矩，就反过来让三行也按丁，把「齐了」改成「四行都按丁，只是三个有保人」。
- [x] Q3 :: “你不知道。”／“我知道。”她说，“我写错一个字，他来了对不上。” :: 【high】郭氏从「记不住」改成「我知道」，直接推翻第 8 章苗青当着书吏说的「她记不住。七个月了。一提就哭」，本章无人回收这句话，苗青也不作反应。读过上一章的读者会以为作者悄悄改了设定：她既然记得，上一章那场说不出名字的戏就成了假的，苗青「不为稳定人心瞒报」的底线也跟着消失。 :: 在苗青扶她走那句前加一拍，把上一章的话接住：苗青当面承认那是替她挡官差（「上回她记不住，是我说的。她记得，是不肯说」），周砚不逼她，仍旧只落夫家姓加保人。或者反过来删掉「我知道」，让她一被问又说不出来、只肯说姓，把「怕写错对不上」改成周砚替她猜出来的判断。
- [x] Q4 :: “北头软一分。”韩松说，“昨天一分半，今天一分。” :: 【medium】墙的软硬与前两章记的数不一致：第 7 章二十一日复摸西墙北头是「软一分」，第 8 章二十二日书吏走后韩松再说还是「软一分」，本章二十三日记成「昨天一分半」。同一个位置昨天的数被改成一分半，读者会以为作者记错，后面「再有一天，硬」也就失去依据。 :: 把昨天的数改回与前两章一致：「北头软一分。前天一分，昨天一分，今天还是一分」；若要显示变化，改成「昨天一分二，今天一分」，同时把第 8 章收尾那句「软一分」统一成同一口径。
- [x] Q5 :: “六担。”苗青说，“原来八担。少那两担是堡外的，他们自己来挑。”／“一天四担，二升。” :: 【medium】水担口径三处打架：阿六提上来六担、苗青划六道，「一天四担」又只澄四担，而第 8 章书吏记的是井出八担、营里四担、堡外两担；且手提只出六担，堡外那两担再自己来挑，井又变成八担，六加二对不上六。 :: 只留一种口径并写全：手提一天只出六担（原八担），其中营里四担、堡外两担由堡外用外头那根绳自己提，阿六只管营里四担，木板上应划四道；若保留六道，就写成营里六担、堡外另提两担，并把「一天四担」改成六担。二选一，别让两个数同时在场。
- [x] Q6 :: “寅，粮。”祝敏念，“三石二斗。现有四斗二升，差二石七斗八升。十六口，一口二斗。郭氏那一口营账垫，明年春。” :: 【medium】粮债只抄进债单，没有落成任何可验的动作：寅这一条把第 8 章的数又念一遍，除了郭氏一口记营账，二石七斗八升的来源、日子、分摊一个字没有，与弦（八条、三天）、驿道（借两人、二十五定人）不对称。三条债里两条被拆成人和日子，粮这条被原样挪到纸上，读者会觉得这一条被撂下了。 :: 在寅后面加一拍：祝敏把笔停住，指出这一条是空的；周砚要么当场落一个可验的（二十五以前把堡外八口并页、按工分顶粮，十月末前每旬摊几升），要么照实写「粮，无着」四个字，并说一句二十五再定。
- [x] Q7 :: 他把手掌摊平，比了一个高度，“两寸。两寸是五公分。”周砚心里过了一遍，“来年一化，底下跟着掉。掉的不是这两寸，是这一冬。” :: 【low】引号断在中间，说话人不清：「两寸。两寸是五公分。」后面接「周砚心里过了一遍，」同一段又直接续上带引号的「来年一化……」，韩松的台词被一句旁白劈成两半，读者分不清后半句是谁在说。 :: 拆成三行：①“两寸。两寸是五公分。”②周砚心里过了一遍。③“来年一化，底下跟着掉。掉的不是这两寸，是这一冬。”
- [x] Q8 :: 江崇没答。营里能换东西的只有盐，和那包糖。 :: 【low】与第 8 章末尾几乎逐字重复的旁白，同一拍在一个营里第二次出现，且这句是叙述者替江崇下的结论，人物那点沉默的硬度就没了。 :: 把这句换成江崇的动作或原话，例如他把捻好的那段麻丢回绳堆，说「换不来」；判断留给读者。若必须保留旁白，至少换说法和落点，不要与第 8 章同句。
