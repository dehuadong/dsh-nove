# 第 3 章 审稿（第 1 轮）

- 正文版本：1

- [x] Q1 :: 全章字数 :: 2946 字，低于三千的下限；“做小”这个主命题的工序只写到“盖井、挖坑、缩火”三个阶段，每一步都没有真正落到手上。 :: 把“做小”写成三道真工序：井盖扣两遍才成、粮坑一尺深且土要分堆、洼地要“做旧”（扫脚印、踩倒草）。补的必须是人手上的账，不是对话。
- [x] Q2 :: 郑老栓想往南走那一段 :: 他只用一句“这话算不算数”就把走的事放下了，太快；一个把十一个人带出八十里、死了三个的老里正，不会因为一句承诺就改主意。 :: 给他一个能看见的交换：他要亲手下井提一罐水，或者要周砚当着所有人把“井不填”这句说第二遍。
- [x] Q3 :: “死在道上，没人埋”这一段 :: 十九个出去、死了三个，这是郑老栓手里最重的东西，却只用一句话带过，没有一个可以摸的东西，读者记不住。 :: 让他怀里的布袋里装着三个人的东西（一把断木梳、一只鞋、一个没系口的布袋），人不说话，东西替他说。
- [x] Q4 :: 于三的两句问话 :: 先问“界划到哪儿”，又问“过了你们的界算不算出了朔州的界”，两句差得很远，读者看不出他真正要问的是什么。 :: 让他的第三句问话暴露意图：他要的不是界，是“能不能从你们这儿过”，并给周砚一句反问—价钱。
