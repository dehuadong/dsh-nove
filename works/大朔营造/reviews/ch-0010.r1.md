# 第 10 章 审稿（第 1 轮）

- 正文版本：2

- [x] Q1 :: “墙根上拿炭画格。营里剩十个，一人一瓢、一天两回，二十格；郑三的伤口一格，画在最后，先空着。” :: 【high】水账的“十个”与名册冲突：上道六人里有四个是营里的（刘四、郭小六、王氏、石头），另两个是堡外借的；十六口减四应是十二口，不是十个。二十格、四十二斤、八十六斤三个数全跟着错，郑老栓“点完二十一个”也跟着错。 :: “营里剩十个”改“营里剩十二个”，跟着改：二十格→二十四格、二十一个格→二十五个格、四十二斤→五十斤、八十六斤归锅→七十八斤、郑老栓“点完二十一个”改“二十五个”。
- [x] Q2 :: “韩松把台子往里挪了半尺，又挪了半尺。‘上去。’……‘明天动土。’” :: 【high】结尾把“墙停十天”和“台子挪给郑土生够墙头”同时立住，但台子两尺、垛口一丈八，十二岁站上去够不到垛口顶；“明天动土”指墙还是坡上那间也读不出来。压轴那一拍算不清就白落。 :: 让韩松一句话说清台子的去向和孩子的活：郑土生站上去够的是塌口那截没补的土沿（不是垛口顶），明天他去坡上挖坑；“明天动土”改成“明天坡上动土”。
- [x] Q3 :: “吃什么。”“队正管饭。”……“那这六个，管饭不管？”“队正管饭。” :: 【medium】走的人的饭归谁管，本章与第 9 章两个答案：第 9 章是“路上自己起灶”、债单写“口粮照摊”，本章于三连答两次“队正管饭”，郑老栓听完就点头走了。郑老栓整本书只问“管饭不管”，这是他的底线。 :: 于三答完之后补周砚一句“队正管灶，口粮照摊，账在营里”，让郑老栓听见这句才点头，把两个说法接成一条。
- [x] Q4 :: “郑三来的时候左臂上缠着布……郑三用右手把布解开一角，把水慢慢浇上去。” :: 【medium】郑三的刀伤从“肋下三寸”（第 8 章苗青当众报的）变成左臂。这一格水是苗青单给他伤口算的，位置写错，省水这条代价就落偏了。 :: 改成肋下：布缠在肋上，解布时侧身或撩起衣襟，水浇在肋下那道口子上，“绕了三圈”改绕腰。
- [x] Q5 :: “他把册摊在沟口那块平石上，从腰后抽出炭条”／“书吏回左卫了，册还在他手里。” :: 【medium】于三手里那本册没有来历，而且他一边写册、收册，一边说“册还在他手里”，两句话对不上。读者会问这本册是谁的、写上去算不算数。 :: 一句点明：于三带的是队上的底册，正册在书吏手里；再让他说清这本册的归处（带回交队正），不是“册在他手里”这种含糊话。
- [x] Q6 :: “二小抬半筐。他跟阿六搭伙”……“我干的是抬土的活。” :: 【medium】阿六从挑水改成抬土没有一句交代：第 9 章周砚说“你先把水挑上”、他接了郑老栓那副担子，本章他在抬土，担子又回到郑老栓肩上。 :: 补一句交接：郑老栓“水还是我挑”，或周砚“挑水记老栓的工，你抬土，工记你名下还粮”。
- [x] Q7 :: “回程天就黑了。周砚数着人走：郑三的刀伤还没收口；郑土生十二；阿六欠着粮；霍七报不上……一共六个。缺四个。” :: 【low】清单式复述：九个人不能走的理由一条条排开，全是前几页刚演过的，名单又漏了祝敏、郭氏、二小，凑不齐“营里还剩谁”。 :: 删掉这串清单，只留两三条前文没交代过的，这个数留给点名那场一次说清；或换成一个动作把“缺四个”数出来。
- [x] Q8 :: “桩上拿墨画的号：一、二、三，到九”……“一，四七二。”“三，四三七。”“七，四一五。” :: 【low】桩号退回“一、二、三”，与第 7 章立的方位号（东三、南二、西二、北二）不一致；三个读数没有单位也没有量，读者不知道韩松量的是什么、凭什么说“坡是斜的”。 :: 桩号按方位写（东一、东三、南二）；读数后让韩松翻成中文并给差数：“东一四丈七尺二，南二四丈一尺五，差五尺七寸。坡是斜的，仪器是平的。”
