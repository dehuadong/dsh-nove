# 第 5 章 审稿（第 1 轮）

- 正文版本：1

- [x] Q1 :: 第四节，“周砚下到坎下……他伸手，把人的眼睛合上，又被睁开” :: 主语和逻辑不通：人被合眼后“又被睁开”读成尸体自己睁眼，实际想写的是合不住。 :: 改成具体动作，如“把眼皮按下去，手一松，眼皮又弹开一条缝”。
- [x] Q2 :: 第四节，“营里的人站在坑边上，一共十六个，加上躺着的江崇，十七个” :: 人数与前文对不上：十一口流民加五人是十六，收下的伤兵刚死，此时应为十六；江崇原本就在这十六人里，被重复计了一次。 :: 改为“站着的十五个，坎上还躺着江崇，一共十六个”。
- [x] Q3 :: 第二节末“两头各要往里掏一丈二才见硬底”，第三节“下到一丈二” :: 两处对同一件事的说法不一致：一处说往里掏，一处说往下挖，工匠读者会当成两个数。 :: 统一为“往下掏到一丈二见老墙”，横向只写“墙根两头空了二尺”。
- [x] Q4 :: 第三节，韩松报数“五十四方，十三天”，周砚复述“十三天” :: 五十四方按四人一天四方算是十三天半，报十三天偏乐观，与韩松“不打没把握的数”的性格不符。 :: 改成“十三天出头，算十四天”，后文的复述一起改；周砚宣布时也报十四天。
- [x] Q5 :: 第四节，“名姓没有。牌上刻日期”，紧接“阿六……拿炭条在上头写。他不识字，周砚写的” :: “牌”与前面队正的军牌重名，容易误读；另一句动宾先写阿六写、再说他不识字，读者要回读一遍。 :: 改为“木板上刻日期”；后句改成“阿六不识字，字是周砚划的”。
- [x] Q6 :: 第四节，周砚宣布“九方土，六个人，七天”，韩松补“七天里，两天是等” :: 帐算不平：九方按一天一方约九个工，六个人一天多，扣掉两天只剩五天，对不上七天，也削弱了后面“七天一天都不能少”的分量。 :: 让韩松把工日拆开：九方土加拆、凿、落层翻一倍是十八个工，六人三天，加两天等冻土、两天等雨，合七天。
- [x] Q7 :: 第四节，郑老栓“用了三罐水”，周砚答“水三罐” :: 与苗青第二节“一天一罐水，我给他半罐”冲突：三天应是水一罐半。 :: 两处都改成“水一罐半”，与苗青的数对上。
- [x] Q8 :: 第四节埋人后的账目段落 :: 祝敏整章没有一句台词，本章正是“死人怎么入账”的场合，管账的人缺席，功能缺口明显。 :: 在周砚定账之后补一小段祝敏念账的台词，按“按什么、给多少、什么时候”的口径记下这一个人。
- [x] Q9 :: 第四节，“周砚把图纸摊在土上，四角压着石头——秦老卒没来，那四块石头是营里自己的” :: 破折号后的解释与本章无关，读者不知道“秦老卒来不来”为什么要紧，是多余的一句。 :: 删去破折号后的解释，只留动作。
- [x] Q10 :: 全站仪段落，“机器亮了一下，绿光在暗处很小。他支稳，看了一回，读数，把机器关了” :: 开机、架机顺序倒了：先“支稳”再开机才合工程动作，也才能让望风的霍七有用。 :: 调成先架、后开机、读数、关机，中间加一句霍七在坡上报动静。
- [x] Q11 :: 第三节末，“十三年夜里，江崇在坎下……” :: 错字，读起来像“十三年”。 :: 改为“十三，夜里”。
