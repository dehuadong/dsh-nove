# 第 4 章 审稿（第 1 轮）

- 正文版本：3

- [x] Q1 :: 第三节【“写了。”祝敏从井边转过来…“三月里从朔州城换的，一口锅，工分八分。”】 :: 时间线硬伤：五人十月初三才落到白草滩，锅不可能“三月里从朔州城换的”；而且工分制是十月初四才立的，一口旧锅倒推回三月，跟已定事实直接撞上。 :: 改成能对上的来历：锅是从沟外人家收的，或者十月初四入账时记一笔，祝敏报“图上有记，一口锅，谁也拿不走”，不抬具体月份。
- [x] Q2 :: 第五节【水四罐。干粮两块半…】与第一节“一天一罐”、第三节初九九勺 :: 水量对不上：于三每天来取一罐，初八、初九、初十合计三罐；初九还另外给路上的人舀了九勺，但九勺是从罐里分出去的，不能另算一罐。账上却报“水四罐”，多出一罐来路不明。 :: 账上改成“水三罐，另九勺给路人”，或在初九补一句于三多领一罐（并说明给谁），否则读者把四天旧账算一遍就对不上。
- [x] Q3 :: 第五节【石头一条腿，三天不能走】 :: 这条判断没有出处：石头被踢是第三节的事，抬、看、拿布带缠全是苗青的动作，但正文里没有她给石头看过腿的那一笔，账上就突然出现“三天”，跟江崇那次的毛病一样。 :: 在第三节或第五节开头补三个动作：解开裤腿、按膝弯、布带缠上，再说“三天”。
- [x] Q4 :: 第三节队正卸弓【这个给你…下次我来，你把弓弦给我】 :: 两处没有交代：一是于三第一次开价是“私马一匹、三十张弓”，到队正这里只剩弓，马一句没提，读者会以为漏写；二是队正把“弦”当新条件加上来，周砚张口就接，没有还价——这不合他“先问数字和期限、答应必兑现”的口吻。 :: 让队正一句带过马的去处（“马要驮东西，给不了”），周砚当场回期限：“麻绳三股并一股，一张弓一根，三十根，五天。”
- [x] Q5 :: 第三节队伍规模【第一拨是挑夫，二十几个…第二拨是空手的…最后一批一百来号人】 :: 四百人没有落到地上：写成二十几个挑夫、一群空手、夜里一百来号，加起来与“四百人”差得远；读者会觉得队正夸口，而这一章最重要的压力源就是这四百张嘴和四百双脚。 :: 在第三节开头或过道过程中把数报清：前队、中队、后队各多少，挑夫、空手、带伤的怎么分；让“四百”这个数至少出现两次，并且能用它算东西（比如一天多少勺水、留下一夜多少堆火）。
- [x] Q6 :: 第四节夜里抓人【“绳子给我。”“我就想换个饼。”】 :: 这个人立起来又没了：他是夜里偷绳的落单溃兵，交代了“想换饼”“要口水”，还问了明天有没有水，第二天没有任何下文，读者会等他的后续。 :: 要么第二天给一笔（他跟着队伍走了、或他在道边留下什么），要么把问句改掉，不留这个口子。
