# 第 3 章 审稿（第 3 轮）

- 正文版本：4

- [x] Q1 :: 第一节，韩松算墙："两个人夯一方，十六个人…要三天" :: 算术断裂：两个人夯一方、十六个人手即八组，一天八方，三十六方需要四天半，正文却直接结论"三天"；且章纲写的是"三百方土、半个月"，与正文的三十六方差一个量级。 :: 统一口算链：三十六方、一天八方、三天只夯到二十四方，剩十二方空着——"只有三天"变成不补墙的硬理由，比"补了没用"更有说服力。
- [x] Q2 :: 第二节，祝敏算口粮："账上是十六块…剩八块八…够吃十一天" :: 三处对不上：一是第二章结尾账上是十六块半（正文写纸盖上的 16.5），本章写成十六块；二是按一天两块四，八块八只够三天多，不可能"够吃十一天"；三是"十一天以后是十月十八"的时间推算又恰好正确，读者会以为只是笔误而忽略。 :: 从十六块半起算，三天吃掉七块二，剩九块三；按两块四只能撑到十月十四，砍到不干活十五分之一后一天两块一，撑到十月十五——离入冬只差几天，压力反而更实。
- [x] Q3 :: 第二节开头："霍七这一回说话了。他蹲在最外圈，蹲了一天多" :: 时间线冲突：霍七在第二章结尾当夜才走进火光，到初五天亮不过一夜；"这一回"也与他上一章已经开口相矛盾。 :: 改成"从昨夜起就蹲在最外圈，蹲了一夜"，去掉"这一回"。
- [x] Q4 :: 全章：郑三只在章纲里存在 :: 章纲把"郑三的烧半夜退到天亮又起、退烧药只剩一次的量"列为本章代价，正文里郑三一次没出场，只剩苗青手里一个没打开的纸包，代价落空，烧与药都没有兑现。 :: 在第三节后半夜补一小节：郑三的烧又起来，苗青掰下半片药灌下去，剩下半片重新包紧，说"再烧一回，没了"。
- [x] Q5 :: 第三节，郑老栓摆出三样东西（梳子、穿底的鞋、沾面的布袋） :: 这段停在抒情，没有接进本章的工程判断：全章在讲"做旧"，而三样遗物里最像工具的那只磨穿的鞋、那个沾面的布袋，都没有被用起来。 :: 让周砚索要那只穿底的鞋去踩出往南的脚印（鞋印跟旁人不一），布袋底的炒面渣沿道撒几粒；郑老栓问"还拿得回来不"，周砚答"印子两场风就没了，鞋给你留着"——物件同时承担掩迹与人物关系。
- [x] Q6 :: 第二节，郑老栓追问"补回来？拿什么补"处："我们去人家里……不是。" :: 这句改口含混：读者读不出他原本要说什么，而且字面上像在盘算去抢流民，与他"井不填、水不换人"的立场冲突。 :: 改成从溃兵身上算账：四百人过完，道边会剩下他们背不动、嫌霉的粮，捡回来多少算多少；收尾一句"人要是走没了，粮再多也捡不回来"。
- [x] Q7 :: 第一节，郑老栓："俺们有个远亲在城里给人看仓" :: 凭空多出一个"远亲"新设定，后文没有任何回收；且与第一章"他怕官家许了话随后把人拉走"的动机抢戏。 :: 删掉远亲，改成"到城里去，听说有人往城里挑粥"这类传闻，仍由周砚用一百二十里、九十六碗水拆掉。
- [x] Q8 :: 第二节石头插话（霉豆、"俺一进城就闻见味儿了"）与第三节江崇的辘轳长段 :: 台词辨识度与口吻越界：石头两句都像韩松的反问，去掉名字分不清；"一进城"与场景（白草滩洼地）对不上，流民是从黑石口一路走来的。江崇在文风基准里"只说能或不能"，却讲了一整段假设，信息重要但口气不对。 :: 石头改为具体动作加实物经验（抠袋角、翻口袋只见碎渣），"进城"改"在黑石口的营里就闻过这味儿"；江崇压成短句："要是有棵树。三天，给你做个辘轳。一天三十罐。"，让苗青用"五天"压回去。
- [x] Q9 :: 第四节结尾：周砚认下"我"之后 :: 认下假身份没有任何代价与反应：于三行礼、问界、开价，周砚一句"我"把风险全接了下来，但没人为这个"认"付出任何东西，霍七和于三也没有下一步动作，钩子停在"新土看得见"这一层，没压到"明天怎么办"。 :: 让于三临走再补一句队正的话——来了总得给一口水，喝完就走；周砚握撬棍的手松一下又握紧，再接月光下新翻的土。
