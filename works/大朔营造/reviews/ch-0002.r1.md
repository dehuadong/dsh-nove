# 第 2 章 审稿（第 1 轮）

- 正文版本：1

- [x] Q1 :: “肋上有伤，本来不该下坑”到徒子坑沿那一段 :: 苗青第一章刚下过命令“两天不能动”，郑三却在坑里，且没人拦、事后也没人发作；这是本章最硬的一处规矩失守，被写成顺手一笔，读者的账会算不平。 :: 把规矩和人手直接撞上：苗青发现后当场发作，周砚用“只运土、不下坑、工钱减半”把他改成半个劳力；让“规矩能被执行”和“人手不够”同时成立。
- [x] Q2 :: “编三个筐，三尺的圈” :: 井口三尺，护壁也是三尺，没有余量，筐根本坐不下去；写实口径下这是一个立刻会被读者挑出来的工程错误。 :: 井口三尺，筐二尺八，每边留一寸塞土——把这两寸写成周砚特意留的，反而能显他的经验。
- [x] Q3 :: “四尺够不着。”江崇在旁边说……“先喝上水，再说过冬。” :: 三个人在争一件没交代清楚的事（井深、淘井、口径混在一起），读者会以为江崇在说水位不够深，读两遍才能猜出他说的是淘井。 :: 拆成两个层次：井挖多深能出水（周砚）、井多深能淘（江崇）、两个数字不是一件事。
- [x] Q4 :: “队正说往南走” :: 这一句紧接在“火长孟守业”之后，读者会把“队正”当成同一人；且火长与队正差了好几级，这里含混会拖累后面溃营线的可信度。 :: 点明是“营里的队正”，几百人的头目，与死在沟里的火长不是一个人。
