# 第 1 章 审稿（第 1 轮）

- 正文版本：1

- [x] Q1 :: “明天挖井。沟底下柳丛那边，湿土，挖三尺就有水。” :: 周砚是项目经理，不会在没有依据的情况下报一个具体深度；这句话现在读起来像作者替他许愿，不像他判断出来的。 :: 补一句他的判断依据（柳树根扎得浅、沟底是湿土、碱霜到某一排柳树为止），让“三尺”变成一个可被检验的估计，而不是承诺。
- [x] Q2 :: “十来个人蹲在地上”“那十来个抱着膝盖的人” :: 人数一直是含糊的，但这一章后面要分粮、要记人数、要算明天挖井的人头，含糊会让人数对不上账。 :: 让周砚在坡后数一遍人数，明确十一口人（一个老头、一个孕妇、两个孩子、一个伤号、一个半大少年、四个壮年、两个女人），并且让祝敏把这个数记下来。
- [x] Q3 :: 溃兵跑掉之后到周砚走下洼地之间 :: 地上留了刀和断矛，没人处理，两把撬棍却一直空着手；对一支只有工具的队伍来说，丢掉现成的铁器不合常理。 :: 补一个江崇捡刀的动作：他用脚把刀踢到一边，弯腰捡起，在草上擦两下，不说话。埋下“他们有了第一件铁器”，也埋下江崇对“做兵器”的迟疑。
- [x] Q4 :: 祝敏“记下了”这一处 :: 她说记下了，但纸上什么也没有；这是全书“记账立规矩”的第一次落地，写虚了后面就立不住。 :: 让她把图纸翻到背面，用记号笔画出四列，把十一口人与干粮数写上去，并把这一笔做成一个具体的画面（红漆、图纸背面、写歪的字）。
