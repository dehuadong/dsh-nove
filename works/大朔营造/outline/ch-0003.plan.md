# 第 3 章 章纲

- 视角：周砚
- 目标：在溃兵上道的这三天里，把十六口人和半坑水弄成四百个饿兵路过时“不值得停下来”的样子。
- 阻力：没有墙——韩松算过，补一丈高的堡墙要三百方土、十六个人半个月，三天连一段墙根都夯不起来；郑老栓想带人往南走，可走出去三天路上没水；霍七说溃兵不杀人，先派人摸粮，抢了就走；要藏的东西偏偏只有三样：一口井、一箱干粮、十六张嘴。
- 代价：三天里十六口人先吃掉了本该留到冬天的口粮，账上是十六块往下走到十一块；退烧药只剩一次的量，郑三的烧半夜退到天亮又起；江崇偷着下地动了井口的土，脚比三天前更坏，苗青改了令——五天。
- 结尾变化：第三天夜里，道上先来一个人，穿的是裁短的旧甲、手里没有刀，站在火光照不到的地方问：白草滩的勘界官，是哪一个？周砚那个假身份第一次被人找上门来，而他还得当场决定认不认。
