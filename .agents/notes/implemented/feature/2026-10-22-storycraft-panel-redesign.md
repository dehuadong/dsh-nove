# Agent Note: 故事工坊：面板信息架构与视觉重设计

Status: implemented


## 问题

`WorkDetail` 把卷/章节、真值、写前上下文、素材、导出纵向堆在同一页；真值是五个裸 `<pre>`，英文文件 ID 与中文标题混排。作者无法一眼看出“现在该做什么”，编辑真值也要在长页面里找输入框。

## 决定

### 1. 布局与动作归属

```text
顶部：← 全部作品     标题 / 形态 / 总章 · 已写 · 未处理问题 · 未解伏笔
      主：写第 N 章（写到修订）  次：一次做完 · 刷新 · 导出 · 更多
标签：章节 | 真值 | 写前上下文 | 素材 | 导出
```

- `tab` 为组件状态，默认 `chapters`；切换标签用 `hidden` 保留已加载面板（ChapterPanel 的视图/版本不丢），真值首次进入才加载。
- 顶部摘要：总章 = chapters.length；已写 = revision > 0；未处理问题 = `openProblems > 0` 的章数（不叫“待审”，未审章不算）；未解伏笔 = 现有 `readWork` 伏笔计数。
- 全书计划三态：无计划（提示先写计划，禁用写作）、已写未确认（主按钮确认计划）、已确认（主按钮写作）。
- 动作归属：
  - 主按钮：已确认计划时 `写第 N 章（写到修订）`；已写未确认时 `确认全书计划`；无计划时提示先写计划并禁用写作；
  - 次按钮：`一次做完`、`刷新`、`导出`；
  - `更多`（`<details>` 菜单）：`抽取文风`、`导出目录`、`字数范围`、`新建卷`、`改名`、`删除`；
  - `确认全书计划` 仍在 header 的条件位置，不折进更多；
  - 写前上下文的章选择/加载移到真值页底部；
  - `状态与伏笔` 移到章节页底部可折叠区。
- 标签切换不清空已加载的 detail；真值首次进入才 `loadBible()`；真值页提供「刷新」按钮。

### 1.1 章节导航

- 倒序：按章号从大到小，最后一章在最上；
- 分页：`PAGE_SIZE=20`，第 1 页最新 20 章；上一页/下一页 + `第 x / y 页`；
- 选中章变化时自动跳到所在页（`floor(index/20)+1`），翻页不改变选中章；
- 倒序下保留卷头，卷按最后一章所在位置出现；
- 章节动作从「上移/下移」改为「前移/后移」，语义仍按章号向前/向后交换，避免倒序视觉歧义；
- 空作品显示空状态。

### 2. 真值卡

中文名映射：

| name | 标题 |
| --- | --- |
| world | 世界观 |
| characters | 人物档案 |
| style | 文风基准 |
| plan | 全书计划 |
| intent | 作者意图 |

- 卡片：标题、英文路径（次要）、`v…`、草稿/只读徽标、前 5 行摘要；
- `editable` 来自 `GET /bible`；plan 永远只读；
- 缺失卡：`新建`（四件）或 `走全书计划确认`（plan）；
- 写前上下文独立成标签，不再混在真值页。

### 3. 编辑抽屉

- 抽屉放在 `.sc-root` 内，`position:absolute; inset:0`，不盖住整个 GUI；遮罩用 `--dsw-alias-bg-mask-1`；
- `role=dialog`、`aria-modal=true`、`aria-labelledby`；打开时聚焦 textarea，Tab 在抽屉内循环；关闭后焦点回触发按钮，触发按钮不存在时回对应卡片；
- 关闭方式：
  - 无未保存：Esc/取消/遮罩关闭；
  - 有未保存：Esc/遮罩/切标签/返回都**拦截并提示**；`取消` 仍可显式丢弃草稿（与 #36 一致）；
  - 宿主关闭整个面板/折叠侧栏不受控，文档说明草稿可能丢。
- 保存按钮底部 sticky；错误留在抽屉内；保存中禁用；
- 复用现有 `bibleEditor`、`/bible/write`、`expectedVersion`；
- `textarea` 用 `ref` 读当前值（#36 实现）。

### 4. 设计原语与 CSS

在 `client.js` 顶部增加渲染助手（不新建模块）：

- `uiButton` / `uiBadge` / `uiCard` / `uiSection` / `uiTabs` / `uiDrawer` / `uiEmpty` / `uiNotice` / `uiIconButton`；
- CSS 变量 scope 到 `.sc-root`：
  - `--sc-space-1..4`（4/8/12/16）
  - `--sc-radius-sm/md/lg`（6/10/14）
  - `--sc-text-xs/sm/md`（11/12/14）
- 只用 `--dsw-alias-*` 颜色；遮罩用 mask token；
- 去掉硬编码 `#...` 与 `rgba(...)`；
- 抽成函数组件：`ChapterTab`、`BibleTab`、`MaterialsTab`、`ExportTab`，`WorkDetail` 只保留数据加载与 tab/drawer 状态。

### 5. 标签/键盘/响应式

- 外层 `role=tablist`，每个 `role=tab`、`aria-selected`、`aria-controls`、`tabIndex`（选中 0，其余 -1）；
- `ArrowLeft/ArrowRight/Home/End` 切换并聚焦；`hidden` 非活动 panel；
- ChapterPanel 内部的「正文/章纲」保持普通 button（`aria-pressed`，不用 tab ARIA），不进入外层 tab 守卫；
- `.sc-root{position:relative;container-type:inline-size}`；`@container (max-width:600px)` 单列、真值卡单列、抽屉全宽；
- 不按窗口宽度写 `@media`；以面板实际宽度为准；
- 抽屉打开锁 `.sc-detail` 滚动，关闭恢复。

### 6. 数据/边界

- 不改 schema；导出页只展示现有 `GET /exports` 的 `{exists,directory}`，加 header 导出按钮与 `/backups` 备份入口；不承诺 TXT/EPUB/MD 逐项状态；
- 不改素材/导出路由；
- 不引入 UI 框架、不新增 npm 依赖、不新增构建步骤；
- 真值未保存时禁止切标签/返回；Esc/遮罩不丢弃；
- 现有 E2E 选择器更新：外层真值改为 `getByRole('tab')`，素材测试先切「素材」，header 摘要不再用「状态事件」旧徽标。

### 7. 测试

- E2E：
  - 默认章节、四标签切换、方向键、`aria-selected`；
  - 真值五张中文卡、plan 无编辑；
  - 抽屉打开/保存/取消、焦点返回；
  - 未保存切标签/返回/Esc 被拦截；
  - characters 坏 JSON 保留输入；缺失可编辑项新建；缺失 plan 无新建；
  - 素材页导入/筛选/改名/删除；导出页/header 导出；
  - 把面板容器设到实测 `clientWidth≈600` 下单列、无横向滚动，抽屉不溢出；不按窗口宽度断言；
  - 取消不产生 `/bible/write` 请求。
- 现有测试更新：素材先切标签；真值用 tab/卡片；header 摘要断言改新徽标；章节动作选择器改前移/后移。
- 新增 25 章分页 E2E：第 1 页倒序 25–6，第 2 页 5–1，翻页/跳页正确。
- 单元无新增（纯前端）；真实 `雪线邮路` 只读走查。

## 备选方案

- **引入 Radix/shadcn/Tailwind**：需要打包/依赖/主题适配，否决。
- **只改配色**：解决不了信息架构，否决。
- **真值继续内联编辑**：长页面里仍难找，否决。
- **拆成多个独立页面**：宿主侧栏空间有限，标签更合适。

## 后果

1. 默认 `章节`；四标签可切换；`aria-selected`/方向键正确；原写作/审稿/修订/定稿动作不回归。
2. Header 动作归属完整：主写作、一次做完、刷新、导出、更多、确认全书计划、抽取文风、导出目录、字数、卷、改名、删除都有入口。
3. 真值五张中文卡；plan 只读；抽屉保存/取消/错误/焦点返回正确。
4. 未保存切标签/返回/Esc/遮罩被拦截；取消不请求；保存后卡片版本更新。
5. characters 坏 JSON 保留输入；缺失可编辑项可新建；缺失 plan 无新建。
6. 素材/导出功能原样；导出页只展示 exists/directory；E2E 更新后全过。
7. 面板实际宽度 600px 下单列、无横向溢出；只用现有令牌；无新依赖/构建。
8. 章节导航倒序、20/页、翻页/选中跳页正确；25 章 fixture 覆盖两页；动作改前移/后移。
9. 真实 `雪线邮路` 只读走查，作者库不动；README、面板内页面说明、#4 E19 同步。

## 风险

- WorkDetail 体量大，重构易回归；拆四个 tab 函数组件，E2E 覆盖主路径。
- 外层 tab 改 ARIA 会改测试选择器；一次性更新。
- 抽屉在宿主侧栏的定位/焦点需真实走查；先容器内 absolute + focus trap。

- `node storycraft/scripts/ci.mjs`：32 个单测文件 + 19 条 E2E 全过。

- 视觉/交互只改前端；后端路由、schema、导出未变。
- 已知未做（记录在案）：内部 primitives 变量化、`更多` 菜单拆分、卡片 5 行截断、抽屉 440px 固定宽。下一轮可继续。
- 视觉改动不改变数据契约；失败只影响展示。

- 交付证据：32 单测 + 19 E2E；四标签、倒序 20/页、真值卡片抽屉、900px 无溢出
