# Agent Notes

写入前读取[记录规则](./README.md)、[项目配置](./config.json)并搜索同主题 Note；适用输入按项目[文档入口](../../docs/AGENTS.md)读取。目录编码生命周期、分类及已选择的上下文，`node scripts/decisions/list.mjs` 可只读查看目录。记录长期有价值的技术提案、设计决定、真实备选及后果；产品合同由工作项或项目指定的独立文档拥有。正文写法遵循项目文档标准。

交付事实与实现保持同步；决定或理由反转时创建新记录。部分替代时互相链接并写清适用范围；完全替代先保留旧记录所有独有的决策依据并修复引用，再考虑删除旧文件。批准证据留在工作项，运行 `node scripts/decisions/check.mjs` 检查机械规则；批准真实性和实际交付仍需审阅。
