# Agent Note：故事工坊：角色代理的输入契约（对拍设计）

## 问题

角色已经拆开（主编 / 规划 / 写手 / 修订者 / 审稿人），但**每个角色该拿到什么**没有定义：

- 写手拿到的是「一份 brief」，不是分层上下文，权威顺序、保护级别、可追溯都没有；
- 规划、审稿、修订各自凭动作里拼的字符串，输入结构各不相同；
- 没有事实白名单，写手自造人名与尺寸时只能靠审稿事后发现；
- 没有轨迹，出了问题无法回答「这一章到底给了它什么」。

## 提案

### 七项输入（每个角色都按这七项定义）

| # | 项 | 内容 | 保护级别 |
| --- | --- | --- | --- |
| 1 | 权威顺序 | 谁的指令优先：作者本轮要求 > 本章 memo > 既成事实/禁令 > 卷纲兜底 | protected |
| 2 | 本章任务 | 章纲五项 / 审稿条目 / 修订条目与模式 / 卷级任务 | protected |
| 3 | 硬约束 | 字数口径、叙事人称、主角名字与行为禁忌、形态规则 | protected |
| 4 | 人物与状态 | 涉及人物的事实、未解伏笔（真实 id）、当前局势 | compressible |
| 5 | 最近脉络 | 最近 3 章摘要、上一章结尾（不是全文） | compressible |
| 6 | 文风与标准 | 写手的文风要点；审稿的判断标准；修订的模式规则 | compressible |
| 7 | 事实白名单 | 上下文中出现的人名、地名、数字与尺寸；**不发给写手，只用于校验** | 校验用 |

**不发给任何角色**：整本正文、全书真值原文、其它作品。

### 各角色的输入差异

| 角色 | 任务（2） | 标准（6） | 白名单（7）用途 |
| --- | --- | --- | --- |
| 主编 | 阶段判断与派活 | 编排方法 | 不适用 |
| 规划 | 卷级或章级任务 | 卷划分与章纲要求 | 校验它没有引用不存在的人与卷 |
| 写手 | 章纲五项 + 作者要求 | 写法与文风 | **拒收自造的人名/地名/数字** |
| 审稿人 | 本章正文 | 审稿标准 | 判定「自造」与「设定冲突」 |
| 修订者 | 条目 + 模式 | 修订幅度与去腔调规则 | 拒收改动引入的新名字/新数字 |

### 预算、保护与轨迹

- 每份输入按段标注 `protected` / `compressible`；
- 超预算时先压 compressible（从「最近脉络」开始，再到「人物与状态」），protected 永不裁剪；
- 每次派活记录轨迹：每段的来源、字符数、是否被压缩或裁掉。轨迹随结果返回，不进主编上下文。

### 与现有实现的关系

- `assembleBrief` 仍然存在，作为**主编自己写**时的兜底上下文；
- 子代理路径不再直接用整份 brief，而是用本契约拼装的上下文包；
- 白名单由拼装器同时产出，交给动作层做校验。


## 各角色对拍输入（按参考实现的字段语义）

下面每一行都对应参考实现里真实存在的输入字段；括号里是我们当前的对应物，缺口写在「差异」列。

### 写手

| 参考字段 | 语义 | 我们的对应 | 差异 |
| --- | --- | --- | --- |
| book config（genre/platform/language） | 题材、平台、语言 | `manifest.form` + 技能 | 缺题材/平台/语言字段 |
| length spec | 目标字数 + 语言换算 | `wordRange` + 字数口径 | 缺「目标值」与「当前值」对照 |
| narrative person | 人称（第一/第三） | 无 | **缺失**，应进硬约束 |
| protagonist authority | 名字、性格锁、行为边界、禁忌 | 人物卡 | 缺「性格锁/禁忌」的结构化字段 |
| book rules / prohibitions | 本书规则与禁令 | 意图文件 | 缺「显式禁令」独立块 |
| style guide | 文风指南 | `bible/style.md` | 有，但没进硬约束块 |
| chapter memo | goal + body（必做要求）+ threadRefs | 章纲五项 | 缺 threadRefs（关联线索 id） |
| context package | 来源 + 选择理由 + 摘录 + 保护级别 | 无 | **缺失**，现在是一锅 brief |
| external context | 外部补充 | 作者本轮要求 | 有，但混在指令里 |

参考**不给**写手：整本正文、全书真值原文。规划才拿「上一章正文」。

### 规划

| 参考字段 | 语义 | 我们的对应 | 差异 |
| --- | --- | --- | --- |
| chapter memo 请求 | 目标是产出一份 memo，不写正文 | 章纲五项 | 有目标，缺 body/threadRefs |
| governed context | 与本章相关的选定来源 | brief 全量 | 未筛选 |
| previous chapter | **上一章正文**（全文） | 上一章结尾摘要 | 参考给全文，我们给摘要；长篇后期应改为「摘要 + 结尾」 |
| length budget telemetry | 目标字数与单位，作为创作约束 | 字数口径 | 缺「这是约束不是判决」的表述 |
| hook id 限制 | 只能引用输入里存在的 id | 事件日志 | 一致，但没在任务里声明 |

### 修订者

| 参考字段 | 语义 | 我们的对应 | 差异 |
| --- | --- | --- | --- |
| revision protocol（按模式） | 每种模式的系统提示 | 修订技能的四模式 | 一致 |
| observations / instruction | 观察清单或作者指令 | 审稿条目 | 有，但缺 impact/fix/mode 的传递 |
| governed context | 选定来源 | 无 | 缺失 |
| length contract | 目标 + 当前计数 | 模式幅度阈值 | 有阈值，缺「当前值」 |
| current chapter（或编号源） | 正文；spot-fix 用带行号稿 | 正文 | 一致 |
| targetText | 定点修改的原文片段 | 无 | **缺失**，我们只能整章回传 |
| onCandidate | 候选稿观察（不采纳） | 无 | 暂不需要 |

### 审稿人

| 参考字段 | 语义 | 我们的对应 | 差异 |
| --- | --- | --- | --- |
| observation 模型 | assessment（issue/resolved/observation）+ evidence[] + summary | 审稿 JSON | 有 problem/where，缺 evidence 编号与 resolved 语义 |
| 章节 + memo | 对照 memo 的必做要求 | 正文 + 章纲 | 有 |
| hook 状态 | 真实 id 与状态 | 事件日志 | 有 |
| 最近推进 | 最近几章的压力/兑现 | 最近 5 章摘要 | 有 |
| 读者承诺 | 未兑现的期待 | 伏笔 | 部分 |
| 行号源 | 便于引用证据 | 无 | **缺失**，证据只能靠引号 |

### 主编 / 归档

| 参考 | 语义 | 我们的对应 | 差异 |
| --- | --- | --- | --- |
| 阶段与闸门 | 现在该做什么 | `story_next` + 闸门 | 一致 |
| 派活与验收 | 派给谁、怎么验收 | 编排技能 | 有，缺轨迹 |
| 状态归档 | 章节事实 → 事件与伏笔 | `story_state` | 一致 |

## 对拍结论：我们缺的不是「更多内容」，而是「结构」

1. **人称、主角锁、禁令**没有独立硬约束块；
2. **上下文包**不存在（没有来源、理由、保护级别）；
3. **memo 的 threadRefs** 与**审稿的 evidence 编号**缺失；
4. **修订的 targetText** 缺失，导致只能整章回传；
5. **轨迹**缺失，出问题无法追溯。

这五项进本提案的切片，而不是继续往 brief 里塞内容。

## 备选方案

- **继续用整份 brief 派活**：权威顺序与保护级别都无处表达，出问题无法追溯；否决。
- **每个角色各写一套拼装**：输入结构会漂移；改为一份拼装器 + 角色配置。
- **把白名单也发给写手**：会变成「允许名单」提示，模型可能照抄；只做校验。

## 验收条件

1. 五个角色各有一份输入契约（七项齐全，缺项写明为什么不需要）；
2. 拼装结果带分段标记与保护级别，超预算时只压 compressible；
3. 轨迹包含每段字符数与压缩/裁掉标记，并随动作结果返回；
4. 写手输出与白名单比对，自造人名/数字被拒收并给出名单；
5. 主编兜底路径仍可用 `assembleBrief`。

## 风险

- 拼装器与 brief 两套逻辑可能漂移：brief 只服务兜底，拼装器服务派活，需在文档里写清边界；
- 白名单过严会误伤（例如合理的新地名）：先作警告、连续两次再拒收；
- 轨迹增加一点实现复杂度，但它是排障的唯一依据。
