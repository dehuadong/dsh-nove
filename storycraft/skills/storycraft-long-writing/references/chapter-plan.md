# 章纲（单章）

章纲回答一件事：这一章谁想要什么、遇到什么阻力、付出什么代价、结尾发生什么不可逆的变化。

## 字段

| 字段 | 含义 |
| --- | --- |
| `perspective` | 视角人物 |
| `goal` | 本章目标 |
| `obstacle` | 阻力 |
| `cost` | 代价 |
| `turn` | 结尾变化（不可逆） |
| `body` | 章纲正文，一段话，不写正文 |
| `threadRefs` | 伏笔 id 数组，可为空 |

## 规则

- 五项必须具体，不许「待定」「见正文」占位；
- 与作品规则、卷图冲突时以真值为准；要改设定先说明，不要在章纲里私改；
- 章纲确认前不写正文；
- 字段示例见 `references/chapter-plan-examples.md`。
