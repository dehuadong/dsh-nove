# 章纲实例与自检

## 反例：五项都写了，但不成章

```
视角：周观
目标：活下去
阻力：敌人很强
代价：受伤
结尾变化：局势更紧张了
```

问题：目标空、阻力虚、代价没有具体损失、结尾变化不可指认。写成这样，写手只能自由发挥。

## 正例（同一场景）

```
视角：周观
目标：今晚把十六口人从塌方的东墙挪到西院，且不惊动巡夜
阻力：只有一盏油灯、两副担架；西院住着不肯让路的李屠户，且他在等一个说法
代价：为借西院，周观答应替李屠户把三天前的账做平，等于把自己拖进粮账
结尾变化：人是挪过去了，但粮账从此有他一份；李屠户开始把他当自己人使唤
```

五项互相咬合：目标具体、阻力是人和处境、代价是新的债、结尾变化指认得出（从「借住」变成「欠人情」）。

## 自检

- 把「目标」单独拿给别人看，他知道人物今晚要做什么吗？
- 「阻力」换成一个更强的人，故事会不一样吗？不会，说明阻力写虚了。
- 「代价」是这一章付的，还是以后才付的？以后才付的移到以后。
- 「结尾变化」能指着一段话说「就在这里变的」吗？不能就并入别章。
- 五项里有没有任何一项其实是支线的目标？有就拆章。

## 卷的自检

- 这一卷结束时，局势比开卷时变了什么？一句话说不清，就还没成形。
- 卷末推力是「发生了什么」，还是「感觉要发生什么」？只要后者，回去补事件。
- 这一卷能不能删掉？能删，说明它没有承担主线的一段。
