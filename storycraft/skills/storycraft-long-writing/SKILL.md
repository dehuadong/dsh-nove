# 长篇共享方法

这份技能只给判断依据：它不产出 JSON、不调用动作、不改阶段，也不替代角色与形态技能的输出契约。

## 用法

当前节点该读哪份参考由 `story_next.method` 给出（`skill` + `reference`）。**只读那一份**，不要一次读完；`reference` 为空表示这一节点不需要额外参考。

参考文件在 `references/` 下：

- `foundation-design.md`：叙事引擎、世界硬规则、卷末不可逆变化、人物弧代价、初始伏笔；
- `chapter-plan.md`：单章章纲五项与规则、示例指针；
- `reader-contract-and-progression.md`：开篇承诺、多轴推进、余波、章纲自检、因果归属；
- `scene-dialogue-and-length-budget.md`：场景预算、对话压力、字数分配、跑偏了怎么修；
- `state-projection.md`：事实投影、伏笔生命周期、投影边界、数值与在场。

## 不要做

- 不要在这里补动作、字段或状态；本实现没有的字段不要编。
- 不要把参考实现的对象或字段当成真值或状态动作的字段。
- 不要因为表格列了多个文件就全部加载；节点只给一份。
