# 篇纲（短篇）

短篇只有一篇，篇纲要一次说清整篇的走向。

## 字段

| 字段 | 含义 |
| --- | --- |
| `perspective` | 视角人物 |
| `goal` | 主人公要什么 |
| `obstacle` | 阻力 |
| `cost` | 代价 |
| `turn` | 结尾反转或回响 |
| `body` | 篇纲正文，一段话 |
| `threadRefs` | 伏笔数组，可为空 |

## 规则

- 单一核心转折，不要在一篇里塞两条主线；
- 开头一次钩子、结尾一次回响，中间靠压力推进；
- 篇纲确认前不写正文（协议闸门 `plan-approval`）。
