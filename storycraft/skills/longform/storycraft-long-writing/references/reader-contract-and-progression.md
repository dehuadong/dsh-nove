# 读者承诺与推进

## 开篇承诺

- 第一章先给正在发生的压力，再给背景解释；第一屏要有具体的扰动、矛盾、风险或未回答的事实。
- 只介绍撑住这个压力所需的人与规则；其余人物与设定后置。
- 第二章用一次可见的使用与后果，证明主角的特殊筹码、信息、限制或能力，不要用说明替代。
- 第三章让下一个短期目标通过动作变得清楚。
- 这些是商业连载的默认方法，不是对作者选定的文学节奏、题材与形态的否决权。

## 承诺要持续兑现

- 开篇定下读者会反复得到的体验：什么样的紧张、愉悦或问题。
- 后续章节可以变速，但要通过具体事件继续供给这份承诺；不能只在章纲里重复承诺。
- 伏笔不是靠「提到」维持：必须有人依据证据行动、付出代价、做出选择或改变理解。
- 兑现之后先写余波，再起下一轮升级；不要用连续的兑现把读者推到麻木。

## 多条轴推进

- 一章至少改变一条主轴与一条辅轴：情节位置、知识、关系、地位、危险、资源、自我认识。
- 安静章也要有持久变化；没有变化的安静章可以并入别章。
- 按短戏剧循环安排连载，而不是孤立地排章。

## 章纲要能回答

- 这一章的直接动作是什么。
- 读者此刻在等什么，本章是兑现还是有意延迟。
- 安静节拍承担什么功能。
- 人物的选择为什么只能这样。
- 章末状态变了什么。
- 哪条伏笔被推进，以什么状态推进；推进或回收只引用账本里已有的伏笔文本，新种下的伏笔用最终措辞。
- 这些答案写进现有五项（通常是目标或结尾变化）；正文写进 `body`，伏笔 ID 写进 `threadRefs`，不要另造字段。

## 因果归属

- 后果来自人物在约束下的选择；不要用巧合、无来由的能力或对手突然失误解决压力。
- 新事实改变路线时，要写清它怎么被发现、为什么现在才重要。
- 事件发生的时间与主角发现它的时间分开；不要把过去的事挪到当下。
- 重要物件在开启、移动、改动前，保留它原有的持有人、取用规则与可见的交接。

## 占比

- 作者给的线占比要通过场景、对话、行动、证据与关系变化实现，不能靠计划里重复百分比。

## 章纲字段

| 项 | 要求 |
| --- | --- |
| 视角 | 这一章跟着谁的眼睛走；一章内不切换，除非有明确的场景分隔 |
| 目标 | 这一章里，视角人物想要的具体东西（不是「想活下去」这种空目标） |
| 阻力 | 谁或什么在阻止他；必须是具体的人、规则或处境 |
| 代价 | 他为了推进付出了什么；没有代价的推进不算推进 |
| 结尾变化 | 章末与章初相比，局势、关系或认知变了什么；写不出变化就并入别章 |

五项必须能互相咬合：目标被阻力挡住，代价让选择变难，结尾变化来自这次选择；视角决定谁能看见这条因果链。

## 单章写作纪律

- 人物做什么必须能被其目标与处境解释；解释不了就改行为，而不是补一段心理独白。
- 每章至少一个具体可感的细节（物件、动作、对话里的口气），不要只写情绪判断。
- 不用「他知道，这一切都变了」这类总结句代替事件。
- 对话承担信息与立场冲突；连续三段以上纯对话没有动作或环境，就要重写。
- 时间线、称谓、地名、能力边界与既有设定冲突时，以设定为准，改新写的部分。

## 单章自检

- 本章目标是否在结尾发生了变化？没有变化就不是一章。
- 有没有一段可以整段删掉而不影响后文？有就删。
- 人物台词去掉名字后，还能分辨出是谁在说吗？
- 新出现的事实是否与既有设定冲突？冲突是否已在正文里被处理？
- 结尾是否给出下一步的具体期待（而不是「暴风雨即将来临」这种空话）？
