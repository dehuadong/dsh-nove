# 长篇：正文

## 判断标准

- 目标变成场景：即时目标、阻力、转折、留得住的后果；
- 人物选择服从他想要什么、知道什么、怕什么、付得起什么；
- 信息靠动作、证据、对话与感官细节释放，不用旁白总结；
- 每段都要改变冲突、证据、情绪、关系、认知或处境，否则删掉而不是注水；
- 保留作者的视角、口吻与禁区。
