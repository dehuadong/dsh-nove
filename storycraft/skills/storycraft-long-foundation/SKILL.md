# 长篇：基础设定与全书计划

## 判断标准

- 前景线要能看见，深处要有一条因果线在推；
- 每一卷都有可观察的末态与不可逆变化，不靠续写硬拖；
- 人物弧要付代价，代价落在具体事件上；
- 区分休眠的种子与已经生效的承诺；初始伏笔只种能收回的。
