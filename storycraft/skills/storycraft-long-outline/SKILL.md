# 长篇：全书计划

## 判断标准

- 主线要能看见起点、压力、代价与可能的结局方向，不写成简介；
- 每一卷有可观察的卷末变化与进入下一卷的推力；
- 结局方向要写明哪个问题必须被回答、哪种代价必须被支付；
- 只种能收回的初始伏笔，区分休眠种子与已激活承诺。
