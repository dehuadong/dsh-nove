# 剧本共享方法

剧本按「集」卖，观众按「秒」决定去留。第一职责是让每一集在最后十秒把观众推去下一集。

## 用法

当前节点该读哪份参考由 `story_next.method` 给出。**只读那一份**；`reference` 为空表示这一节点不需要额外参考。

参考文件在 `references/` 下：

- `spec.md`：spec 与场次字段、规则；
- `episode-scene-craft.md`：卖点、集数/时长、人物动机表、钩子链、场次格式、写作流程与自检。

本技能只提供判断依据，不产出提交内容；具体提交 schema、闸门与失败回退由当前角色/形态技能规定。

## 不要做

- 不要把剧本写成小说段落：只写镜头能拍到、话筒能录到的内容。
- 不要在这里补动作、字段或状态；本实现没有的字段不要编。
- 不要因为列出了两个文件就全部加载。
