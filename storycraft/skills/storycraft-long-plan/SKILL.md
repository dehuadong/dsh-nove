# 长篇：章纲

## 判断标准

- 五项（视角、目标、阻力、代价、结尾变化）必须具体，任一为空就不成立；
- 这一章必须改变冲突、证据、情绪、关系、认知或处境之一；
- 结尾变化要留下不可逆的后果，下一章才有压力；
- 不重复上一章的节拍；重复就是没推进。
